B. PROJECT REPORT (REPORT.MD SPECIFICATION)

# ARTEMIS — PROJECT REPORT & APPLICATION ARCHITECTURE

1. PROJECT DESCRIPTION
Artemis is a non-custodial token launchpad that turns a chat conversation into a live
on-chain token on Robinhood Chain (EVM) and Solana. The user describes a coin idea to an
AI copilot, reviews exact launch parameters, then signs from their own wallet — the server
never signs and never holds funds. On Hood mainnet the flagship path is one atomic
transaction (ERC20 deploy + Uniswap V2 pool funding via ArtemisLauncher, source-verified
at 0xeea9d0f7ee0958c6d59f25162be4e69ba60a0f71); on testnet the same UI rehearses a
token-only drill; on Solana the pump.fun rail is built and parked behind a coming-soon gate.

2. CORE CAPABILITIES
- Atomic 1-Tx Launch: token deploy + pool funding + remainder sweep + Launched event,
  all-or-nothing on Robinhood Chain mainnet.
- AI Draft Copilot: free text becomes a validated draft (name/ticker/pool/liquidity/chain).
- Exact Pre-Sign Review: live gas estimate, slippage presets, chain-time deadline,
  balance check, router authenticity verification.
- Proof-Gated Showcase: listings require onchain creation or pool proof; touch-only
  transactions are rejected.
- Enforced 1:1 Artwork: crop modal + IPFS pinning for consistent catalog cards.
- Resume-Safe Receipts: localStorage receipts resume interrupted 2-step launches without
  double-funding and survive DB outages.

3. END-TO-END APPLICATION FLOW (USER & SYSTEM WORKFLOW)
[Step 1: Draft]
- User opens https://artemis-olive.vercel.app, chats an idea or fills the Launch Parameters
  form (target network 4663/46630, supply fixed 999M, pool allocation, ETH liquidity).
- Artwork file goes through the 1:1 crop modal, then pins to IPFS (EVM showcase path).

[Step 2: Review]
- Review dialog shows live cost breakdown (liquidity + network fee + total), slippage
  tolerance, and deadline; wallet connects and switches to Hood chain; router is verified.

[Step 3: Execute]
- Mainnet 4663: one atomic launchOneTx (token + pool + LP to creator, remainder swept).
- Testnet 46630: deployToken then addLiquidity, resumable without double-fund.
- Receipt saved locally at each milestone.

[Step 4: Showcase]
- POST /api/community/tokens verifies the tx onchain, saves to Postgres, lists on
  https://artemis-olive.vercel.app/tokens with artwork; local receipts render as
  dashed cards with chain names and avatars even when the DB is offline.
